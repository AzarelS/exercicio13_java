# Lista de Exercicios: Estruturas de Selecao em Java

Repositorio academico destinado ao armazenamento e organizacao de exercicios praticos desenvolvidos para a disciplina de programacao em Java da **UNISUL**, sob a supervisao do professor **Osmar**.

O objetivo deste projeto e consolidar o aprendizado sobre o fluxo de controle condicional, aplicando conceitos fundamentais de tomada de decisao na linguagem Java.

## Tecnologias e Requisitos

* **Linguagem:** Java (JDK 11 ou superior)
* **Ambiente de Desenvolvimento:** Qualquer IDE compativel com Java (Eclipse, IntelliJ IDEA, NetBeans) ou editor de texto com terminal.

## Topicos Abordados

Os algoritmos presentes neste diretorio cobrem os seguintes conceitos de estruturas de selecao:

* Condicionais simples e compostas (`if`, `else`)
* Condicionais aninhadas e encadeadas (`else if`)
* Selecao multipla (`switch-case`)
* Aplicacao de operadores relacionais e logicos (`&&`, `||`, `!`)

## Instrucoes de Compilacao e Execucao

Para executar os codigos atraves da linha de comando, siga os passos abaixo:

1. Abra o terminal no diretorio raiz onde o arquivo `.java` esta localizado.
2. Compile o codigo-fonte utilizando o comando:
   ```bash
   javac exercicio13_java.java
   ```
3. Execute o programa compilado com o comando:
   ```bash
   java exercicio13_java
   ```
